I turn ambiguous product ideas into working, verifiable systems using AI-assisted development.

My strongest work is not “prompt once and hope.” I define the target, decompose the problem, direct coding and research agents, inspect what they produced, diagnose failures, and keep iterating until the result can be checked against evidence.

## Selected work

### [Aegis Operator](https://github.com/aisarus/aegis-operator)
A local autonomous development operator built around acceptance contracts, worker routing, evidence-driven verification, replanning, budget awareness and owner control.

**The interesting part:** models are allowed to reason; deterministic runtime owns facts, limits, evidence and dangerous boundaries.

### [Lamdan](https://github.com/aisarus/syllabus-to-os)
An AI-first academic workspace for turning course material into structured, source-linked study artifacts while keeping generated content reviewable instead of pretending it is authoritative.

### [BotForge](https://github.com/aisarus/ai-employee-forge)
A SaaS / automation prototype that evolved from a simulated Lovable frontend into a real Supabase + Edge Functions + Telegram integration, including security hardening after generated shortcuts were found.

### Small experiments

- [TWIN](https://github.com/aisarus/Twin) — deterministic CSS/SVG motion timeline.
- [Djbrain](https://github.com/aisarus/Djbrain) — interactive Three.js procedural visualization.
- TRI·TFM — an ongoing family of proposer / critic / verifier and prompt-optimization experiments.
